PureZip Privacy Policy / PureZip 隐私政策

Last Updated / 更新日期： 2026-10-14

[中文] PureZip 是一款 Windows 平台纯粹、无广告的本地压缩解压软件。本软件不会收集、上传任何用户个人信息、文件内容或本地文件路径。所有压缩和解压运算全部在用户本地电脑执行，不会把任何用户数据上传到外部服务器。

[English] PureZip is a pure, ad-free local compression and decompression software for Windows. This software does not collect or upload any personal user information, file contents, or local file paths. All compression and decompression operations are performed entirely on the user's local computer, and no user data is uploaded to external servers.

1. Data Collection / 数据收集

[中文] 本应用不采集用户名、邮箱、文档、图片等任何用户隐私数据。仅微软商店系统会记录您的购买授权信息，该信息由微软平台管理，遵循微软隐私政策。

[English] This application does not collect any user private data such as usernames, emails, documents, or images. Only the Microsoft Store system records your purchase authorization information, which is managed by the Microsoft platform and follows the Microsoft Privacy Policy.

2. Third-Party Services / 第三方服务

[中文] 软件仅调用微软商店原生 API 校验购买许可，不会向任何第三方发送用户信息。

[English] The software only calls the native Microsoft Store API to verify purchase licenses and does not send user information to any third parties.

3. Contact Us / 联系我们

[中文] 关于隐私相关疑问，请访问技术支持页面发送邮件。

[English] For privacy-related inquiries, please visit the support page to send us an email.
